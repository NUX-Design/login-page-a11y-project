# Login Page Project

โปรเจกต์หน้า Login แบบ static สำหรับ platform ทั่วไป สร้างด้วย HTML, CSS และ
JavaScript โดยเน้นโครงสร้างที่เรียบง่ายและแก้ไขต่อได้ง่าย

## Features

- หน้าเข้าสู่ระบบสำหรับผู้ใช้งานทั่วไป
- ช่องกรอกอีเมลและรหัสผ่าน
- ตัวเลือกจดจำการเข้าสู่ระบบ
- ลิงก์สำหรับการกู้คืนรหัสผ่าน
- การแสดงข้อความสถานะหลังส่งฟอร์ม
- Layout ที่ปรับตามขนาดหน้าจอ

## Getting started

โปรเจกต์นี้ไม่มี Package ที่ต้องติดตั้ง

1. Clone โปรเจกต์นี้
2. เปิด `index.html` ใน Browser หรือใช้ Live Server
3. ทดลองกรอกข้อมูลและส่งฟอร์ม

สำหรับการรันเป็น local server สามารถใช้คำสั่งนี้จากโฟลเดอร์โปรเจกต์:

```bash
python3 -m http.server 4173
```

จากนั้นเปิด [http://127.0.0.1:4173/index.html](http://127.0.0.1:4173/index.html)

## Project structure

| ไฟล์ | รายละเอียด |
| --- | --- |
| `index.html` | โครงสร้างหน้า Login |
| `styles.css` | Layout, สี และรูปแบบการแสดงผล |
| `script.js` | พฤติกรรมการส่งฟอร์มและข้อความสถานะ |
| `AGENTS.md` | แนวทางสำหรับ AI และผู้ร่วมพัฒนา |

## Development notes

- รักษาโค้ดให้เป็น vanilla HTML, CSS และ JavaScript เว้นแต่มีเหตุผลจำเป็นต้องเพิ่มเครื่องมืออื่น
- ทดสอบหน้าใน Browser หลังแก้ไข UI หรือพฤติกรรมของฟอร์ม
- ตรวจสอบทั้งหน้าจอขนาดกว้างและหน้าจอมือถือ
- อธิบายข้อจำกัดหรือสิ่งที่ยังไม่ได้ตรวจสอบเมื่อส่งมอบงาน
